## chamados-ti

Descrição:
Demandas de suporte técnico corporativo, acesso de usuário, notebook, desktop, VPN, e-mail, impressora, sistemas internos usados pelo colaborador e problemas gerais de infraestrutura de TI.

Palavras-chave:
- vpn
  Perguntar:
  - Qual sistema ou recurso você está tentando acessar?
  - Qual erro aparece?
- notebook
  Perguntar:
  - Qual o patrimônio, modelo ou identificação do equipamento?
- e-mail
  Perguntar:
  - O problema é envio, recebimento, login ou configuração?

## chamados-dados

Descrição:
Demandas relacionadas a dados, relatórios, dashboards, métricas, pipelines analíticos, consultas, qualidade de dados, BI, tabelas, bases, indicadores e extrações.

Palavras-chave:
- dashboard
  Perguntar:
  - Qual dashboard ou relatório está com problema?
  - Qual métrica, filtro ou período parece incorreto?
- base
  Perguntar:
  - Qual base, tabela ou fonte de dados está envolvida?
- indicador
  Perguntar:
  - Qual indicador está divergente?
  - Qual valor esperado e qual valor atual?

## chamados-people

Descrição:
Demandas de RH e People, incluindo folha, benefícios, férias, admissão, desligamento, ponto, documentos de colaboradores, políticas internas e dúvidas trabalhistas.

Palavras-chave:
- férias
  Perguntar:
  - Qual período desejado ou em análise?
- benefício
  Perguntar:
  - Qual benefício está envolvido?
- ponto
  Perguntar:
  - Qual data ou período precisa de ajuste?

## chamados-plataforma

Descrição:
Demandas relacionadas à plataforma do produto, backend, frontend, APIs, deploys, ambientes, bugs de aplicação, integrações, performance e comportamento do sistema em produção ou homologação.

Palavras-chave:
- api
  Perguntar:
  - Qual endpoint ou integração está envolvida?
  - Qual status code ou erro retornado?
- bug
  Perguntar:
  - Qual tela, fluxo ou funcionalidade apresentou o problema?
  - Quais passos reproduzem o erro?
- deploy
  Perguntar:
  - Qual serviço ou versão precisa ser publicada?

## chamados-seginfo

Descrição:
Demandas de segurança da informação, incidentes, phishing, permissões sensíveis, vazamento de dados, revisão de acesso, MFA, vulnerabilidades, compliance e análise de risco.

Palavras-chave:
- phishing
  Perguntar:
  - Você recebeu por e-mail, Slack ou outro canal?
  - Consegue anexar ou descrever o remetente e o conteúdo?
- acesso sensível
  Perguntar:
  - Qual sistema e qual perfil de acesso está sendo solicitado?
  - Existe aprovação do gestor?
- vulnerabilidade
  Perguntar:
  - Qual sistema, serviço ou repositório está envolvido?
  - Existe evidência, CVE ou relatório técnico?
